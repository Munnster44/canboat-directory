README / Help — What This App Does and How to Use It

What the app does

The CPS-ECP Excel Member Directory is a browser-based search and lookup tool for CanBoat / CPS-ECP membership data. It loads an Excel or CSV membership file directly in your browser and lets you quickly search, filter, browse, and review individual member records without changing the source file.

Main features

  • Loads .xlsx, .xls, and .csv membership files.
  • Searches by District, Squadron, First Name, Last Name, User ID, Family UserID, Family Head Uid, Member ID, Email, Postal Code, Next Payment Date, and other membership fields.
  • Filters records from the search area at the top of the page.
  • Provides a second set of filters inside the record listing so you can narrow individual columns.
  • Supports multiple listing-column filters at the same time.
  • Displays records in pages with selectable page sizes.
  • Opens a full Member Details panel when a record is selected.
  • Keeps all processing local to the browser; the loaded membership file is not uploaded by this app.

How to use the app

  1. Click Load Excel Member File.
  2. Select the membership .xlsx, .xls, or .csv file from your computer.
  3. Wait for the status message confirming how many member records were loaded.
  4. Enter one or more values in Membership Search Options. Text fields can use partial values; dropdown fields use exact selections.
  5. Click Search to display the matching records.
  6. To narrow the displayed list further, type into one or more Filter boxes directly below the table headings.
  7. Use Clear All Filters or Reset to return to the full loaded list.
  8. Select the checkbox beside a member record to open the Member Details section.
  9. Use the page-size selector and navigation arrows to move through large result sets.

Family membership searches

Family UserID corresponds to the source Excel column named UserID. Family Head Uid can be used to locate records tied to the same family head. This allows family-related records to be found without changing the headings in your source membership file.

Supported membership columns

The app is designed for these columns when present in the source file:

User ID, First Name, Last Name, Next Payment Date, Auto Renew Enabled, Member ID, Language, Address 1, Address 2, City, Province, Country, Postal Code, Home Phone, Work Phone, Email, Membership Type, District, Squadron, UserID, Family Head Uid, Family Role, Canadian Yachting, L'Escale Nautique, No Magazine, Roles.

Note: Column names should remain consistent with the membership export. The app changes the displayed label UserID to Family UserID, but continues to read the original UserID column from the source file.

Privacy and file handling

The app runs locally in your web browser. Membership data is read into the current browser session for searching and display. Closing or refreshing the page clears the loaded data, and the original Excel/CSV file is not modified.
